# Issue tracker: GitHub

Issues and specifications for this repository live in GitHub Issues for `huxiaoheng44/xiaoheng-web-v3`.

## Conventions

- Create issues with the GitHub CLI: `gh issue create --title "..." --body "..."`.
- Read an issue with its comments and labels before acting on it.
- Apply and remove labels with the GitHub CLI.
- Close an issue only after its requested work is complete.

## Pull requests as a triage surface

**PRs as a request surface: no.**

External pull requests are not treated as incoming feature requests by the engineering skills.

## Skill mapping

When an engineering skill says to publish to the issue tracker, create a GitHub issue in this repository. When it says to fetch a ticket, read the corresponding GitHub issue and its comments.
