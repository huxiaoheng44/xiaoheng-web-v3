Image rectification

Dense matching

Once the fundamental, essential, translation and rotation matrices are known, the rectified pair is used to calculate a disparity map.

Block Matching (BM)

  • Once correspondences lie on parallel epipolar lines, the left image can be scanned line by line.
  • For each pixel, find “similar” pixels in the right image.
  • Individual pixels are hard to match, so a block of flattened pixels of size K×K is used.
  • The difference along the x-axis gives the disparity.

Similarity is measured as the sum of absolute differences (SAD) between two K×K windows flattened to vectors wL, wR:

SAD(x, y, d) = ‖ wL(x, y) − wR(x − d, y) ‖

Semi-Global Block Matching (SGBM)

  • “Global” because it considers information available in the whole image.
  • It does so by considering neighbouring pixels in multiple directions to calculate the disparity.
  • Again a K×K block is used, and 8 directions around it are considered.
  • The direction with the minimum aggregated matching cost is used to calculate the disparity.
  • Uses the Birchfield–Tomasi dissimilarity to find “similar” pixels. For left and right images with columns xl, xr on the same scanline, symmetric functions are defined using the linear interpolation functions Îl, Îr of the image intensities Il, Ir; the minimum of the two gives the dissimilarity.

d̄(xl, xr, Il, Ir) = minxr−½ ≤ x ≤ xr+½ | Il(xl) − Îr(x) |

d(xl, xr) = min{ d̄(xl, xr, Il, Ir), d̄(xr, xl, Ir, Il) }

With D the dissimilarity term and R a regularisation term computed from neighbouring pixels, the total cost minimised for the disparity is E = D + R.

Generated disparity maps

Dense matching evaluation

The generated depth map is compared pixel-wise with the ground-truth depth map. A pixel counts as an error when its difference exceeds both 3 px and 5 %:

Error = count( |dij − d′ij| > 3 px & |dij − d′ij| / d′ij > 0.05 ) / total valid pixels

3D model generation

Conclusion

  1. Implemented a stereo reconstruction pipeline.
  2. Covered key steps such as calibration, key-point calculation and 3D model construction.
  3. Results show the ease and efficiency of reconstructing 3D models from stereo images.
  4. The generated 3D models have potential applications in scene understanding, object recognition and navigation.

Discussion

  1. The project serves as a starting point for further research and development.
  2. ICP methods and other data could be incorporated for improved 3D models.
  3. New applications could be explored in fields such as robotics and autonomous vehicles.
  4. There is room to improve the accuracy and robustness of the 3D models.
  5. New algorithms and techniques could be integrated for better performance.
