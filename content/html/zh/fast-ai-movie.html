FAST AI Movie Web

一个把文字和图片转化为带 AI 讲解员的定制培训视频的 Web 平台——用户可以编辑生成视频的每一个部分。

  • 前端
  • 可复用组件
  • 视频编辑
  • AI 视频生成

项目概览

  1. 输入文字和图片
  2. →
  3. 为视频选择讲解员
  4. →
  5. 定制化培训视频

用户流程

  1. 配置企业视觉设计（Corporate Design）
  2. 上传已有的产品说明书、合规条例等
  3. 配置附加设置
  4. 生成视频
  5. 保持视频内容最新

我们的工作

生成视频并使其可编辑——包括章节文字、音频、幻灯片、图标和测验题——以及企业设计配置、管理员设置、素材管理和内部可视化。

章节编辑功能

编号功能
①新增子章节（major）
②选择子章节标题
③A：子章节上移 · B：子章节下移 · C：新增子章节
④删除子章节
⑤播放音频
⑥选择章节标题
⑦删除整个章节

章节概览功能

  1. 点击折叠或展开章节概览。
  2. 高亮显示当前正在查看的子章节。
  3. 点击跳转到对应的子章节。

图片组件功能

  1. 从本地上传图片。
  2. 点击编辑图片。
  3. 删除图片。
  4. 将图片从图片列表拖入文本区域即可插入。

图片编辑功能

  1. 编辑焦点区域——移动、缩放和删除。
  2. 删除当前图片。
  3. 基于当前修改复制出一张新图片。
  4. 用当前修改替换原图片。
  5. 新增焦点区域。
  6. 编辑图片设置（边框颜色、背景样式、图片类型：全屏 / 半屏 / 小角落、展示时机）。

可复用组件的集成

  1. 可编辑的文本框组件。
  2. 图片组件（支持拖拽插入和图片编辑）。
