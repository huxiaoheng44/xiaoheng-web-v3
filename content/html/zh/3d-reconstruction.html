图像校正

稠密匹配

得到基础矩阵、本质矩阵、平移矩阵和旋转矩阵后，利用校正后的图像对计算视差图。

块匹配（Block Matching, BM）

  • 当对应点位于平行的极线上时，就可以逐行扫描左图。
  • 对每个像素，在右图中寻找“相似”的像素。
  • 单个像素难以匹配，因此使用大小为 K×K 的像素块（展平为向量）。
  • x 方向上的差值即为视差。

相似度用两个展平为向量 wL、wR 的 K×K 窗口之间的绝对差之和（SAD）来衡量：

SAD(x, y, d) = ‖ wL(x, y) − wR(x − d, y) ‖

半全局块匹配（Semi-Global Block Matching, SGBM）

  • 之所以称为“全局”，是因为它会利用整幅图像中的信息。
  • 具体做法是在多个方向上考虑相邻像素来计算视差。
  • 同样取 K×K 的块，并考虑其周围的 8 个方向。
  • 选择聚合匹配代价最小的方向来计算视差。
  • 使用 Birchfield–Tomasi 相异度寻找“相似”像素：对于同一扫描线上左右图像的列 xl、xr，利用图像强度 Il、Ir 的线性插值函数 Îl、Îr 定义一对对称函数，二者的最小值即为相异度。

d̄(xl, xr, Il, Ir) = minxr−½ ≤ x ≤ xr+½ | Il(xl) − Îr(x) |

d(xl, xr) = min{ d̄(xl, xr, Il, Ir), d̄(xr, xl, Ir, Il) }

记 D 为相异度项，R 为由相邻像素计算的正则项，则用于求视差的总代价为 E = D + R。

生成的视差图

稠密匹配评估

将生成的深度图与真实深度图逐像素比较。当某像素的差值同时超过 3 像素和 5% 时，记为错误：

Error = count( |dij − d′ij| > 3 px & |dij − d′ij| / d′ij > 0.05 ) / 有效像素总数

三维模型生成

结论

  1. 实现了立体重建流程。
  2. 涵盖标定、关键点计算和三维模型构建等关键步骤。
  3. 结果表明，从立体图像重建三维模型简单且高效。
  4. 生成的三维模型在场景理解、物体识别和导航等方面具有应用潜力。

讨论

  1. 本项目可作为进一步研究和开发的起点。
  2. 可以引入 ICP 方法和其他数据来改进三维模型。
  3. 可在机器人、自动驾驶等领域探索新的应用。
  4. 三维模型的精度和鲁棒性仍有提升空间。
  5. 可以集成新的算法和技术以获得更好的性能。
