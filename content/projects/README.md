## 使用建议

- 将每个项目文件中的“网页文案草案”作为项目卡片或详情页初稿，再按实际个人职责补充第一人称表述。
- `assets/<project>/` 内的 PNG 可直接用于 HTML 的 `<img>`、画廊或横向滚动展示；建议在页面中保留简短图注。
- PDF 没有提供的内容（代码仓库、团队人数、发布日期、具体个人分工、线上链接）均未臆测，请在建站时自行补齐。
