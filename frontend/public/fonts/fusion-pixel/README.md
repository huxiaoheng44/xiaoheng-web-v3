# Fusion Pixel web fonts

Author: TakWolf and credited upstream contributors.
Upstream: https://github.com/TakWolf/fusion-pixel-font
Release: https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.01

Unmodified 12px proportional and monospaced `zh_hans` WOFF2 files from the
official `ttf.woff2` release archives. Both include Latin and Chinese glyphs.
The proportional face is used for UI/content; the monospaced face for the terminal/code.

License: SIL Open Font License 1.1. Retain `OFL.txt` and the complete upstream
`LICENSES/` notices when redistributing. No external font CDN is used.
